# 記事分析オフライン検証の確認手順

対象は根拠参照の検証と保存済み結果の検索。サイト画面、公開、Claude呼び出しは対象外。環境はWindows PowerShell、Python標準ライブラリーのみ。実データを外部へ送信しない。

## 回帰確認

`python -B -m unittest discover -s scripts -p test_article_style.py -v` を実行する。

- 正しい本文・根拠行・引用は検証を通る。
- 本文変更、行対応変更、行対応ハッシュ欠落、捏造引用、記事不足、別記事の参照はValueErrorになる。
- 未知ID、正常IDに似た接尾辞付きID、Markdownの下線強調内の未知IDは拒否される。正常IDの下線強調は通る。
- 指定軸の検索だけが返り、該当なしは空配列になる。

## 保存済み資料との照合

承認されたローカル保管先に資料がある場合だけ、保存済み本文、行対応ハッシュ付きmanifest、分類結果を `validate()` に渡す。期待値は対象件数と比較件数が保存記録と一致し、引用・ハッシュ検証が成功すること。資料不足は未実施とし、合成データだけの成功で代用しない。古いmanifestや原文は上書きしない。

異常時は根拠資料や保存先を確認する。エラーを無視して成功記録や公開用成果を作らない。実施件数・結果・未確認範囲はPR本文へ記録する。
